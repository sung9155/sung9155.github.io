### 로또 구매 시뮬레이터
- 구입 매수(최대 500만 장), 번호 선택 방식: 자동(랜덤) / 수동(고정 6개) / 반자동(고정 1~5개 + 나머지 자동)
- 추첨 방식: 장마다 새 회차 / 한 회차 고정
- 구매 간격: 0.1초 · 0.05초 · 0.01초 · 즉시(일괄 계산)
- 실시간 집계: 등수별 당첨 수, 총 구입액·당첨금·손익·회수율, 최고 등수
- 등수별 당첨금 합계 막대그래프, 누적 구입액 vs 누적 당첨금 곡선
- 이론 확률(1등 1/8,145,060 등)과 실측 확률 비교표, 당첨 기록 200건
- 당첨금은 회차마다 달라지므로 기본값은 평균 추정치이며 직접 수정 가능

### 대출 상환 계산기
- 상환 방식: 원리금균등 · 원금균등 · 만기일시
- 대출금액, 연이자율, 기간(개월), 거치기간(이자만 납부), 매월 추가 원금상환
- 요약: 첫 달 납입금, 총 이자, 총 상환액, 실제 상환 개월수(추가상환 시 단축 표시)
- 월별 원금/이자 스택 막대그래프(180회차 초과 시 연 단위 집계), 잔금 곡선
- 상환 방식 3종 비교표(첫 달·마지막 달 납입금, 총 이자, 이자 비중)
- 월별/연도별 상환표, CSV 내보내기
- 월 복리(연이율 ÷ 12) 기준 단순 계산. 실제 상품의 일수 계산·수수료와 다를 수 있음

### 적금·예금 복리 계산기
- 월 적립 + 초기 예치금, 단리 / 월복리, 매년 적립액 인상률
- 이자소득세 15.4% · 세금우대 9.5% · 비과세, 목표 금액 도달 시점
- 납입 원금 vs 평가액 곡선, 월별/연도별 표, CSV 내보내기

### 연봉 실수령액 계산기
- 국민연금(기준소득 상·하한 반영)·건강보험·장기요양·고용보험, 요율 직접 수정 가능
- 근로소득공제 → 인적공제·보험료공제 → 종합소득세율 → 근로소득세액공제·자녀세액공제
- 공제 항목별 막대그래프, 연봉 구간별 월 실수령액 곡선

### 전세 vs 월세 비교
- 전세대출 이자 + 자기자본 기회비용 vs 월세 + 보증금 기회비용
- 월세 세액공제(15% / 17%, 연 1,000만원 한도), 전월세 전환율 자동 계산
- 월 비용 구성 스택 막대, 누적 주거비 곡선

### 은퇴 자산 소진 시뮬레이터
- 몬테카를로(최대 5,000회): 기대수익률·변동성·물가상승률·국민연금 반영
- 자산 유지 성공률, 상위 10%·중앙값·하위 10% 경로, 소진 나이 분포

### 적립식 vs 거치식
- 같은 시장 경로를 두 전략에 동일 적용, 대기자금 이율 반영
- 승률·중앙값·하위 10%·원금 손실 확률, 최종 금액 누적분포(CDF)

### 가챠 확률 시뮬레이터
- 확률·천장·픽업 성공률(픽뚫 보정)·목표 개수·1회 비용
- 평균/중앙값/백분위 뽑기 횟수와 비용, n회 이내 달성 확률, 예산 내 성공률

### 큰 수의 법칙
- 편향 동전(확률 조절)·다면 주사위, 0.1초~즉시 시행
- 비율 수렴 곡선 vs 이론값, 비율 편차와 횟수 편차, 최장 연속 기록
