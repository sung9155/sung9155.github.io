대출 상환 계산기

대출금·금리·기간·상환방식을 넣으면 매달 납입금과 잔금을 표와 그래프로.

  • 원리금균등 · 원금균등 · 만기일시
  • 거치기간, 매월 추가상환 반영
  • 상환방식 3종 총이자 비교, CSV 내보내기
🐖

적금·예금 복리 계산기

월 적립과 초기 예치금으로 만기에 얼마가 되는지, 세금 떼고 얼마 남는지.

  • 단리 vs 월복리 비교
  • 이자소득세 15.4% / 세금우대 / 비과세
  • 목표 금액 도달 시점 계산
💵

연봉 실수령액 계산기

4대보험과 소득세를 뺀 월 실수령액을 추정합니다.

  • 국민연금·건강·장기요양·고용보험
  • 부양가족·자녀 공제 반영
  • 연봉 구간별 실수령액 곡선
🏠

전세 vs 월세 비교

대출이자 + 보증금에 묶인 돈의 기회비용까지 넣어야 진짜 주거비가 나옵니다.

  • 전세대출 이자 vs 월세 + 보증금 기회비용
  • 월세 세액공제(15% / 17%) 반영
  • 전월세 전환율 자동 계산
🌅

은퇴 자산 소진 시뮬레이터

내 돈은 몇 살에 바닥날까? 변동성을 넣고 1,000번 돌립니다.

  • 몬테카를로 성공 확률
  • 상위 10% · 중앙값 · 하위 10% 경로
  • 국민연금·물가상승률 반영
📈

적립식 vs 거치식

목돈을 한 번에 넣는 쪽과 나눠 넣는 쪽을 같은 시장 경로에서 비교.

  • 승률, 중앙값, 하위 10% 비교
  • 최종 금액 누적 분포 곡선
  • 원금 손실 확률

  • 자동(랜덤) · 수동(고정) · 반자동 혼합
  • 0.1초 / 0.05초 / 0.01초 / 즉시 계산

  • 내 예산으로 성공할 확률

큰 수의 법칙

동전·주사위를 실시간으로 던지며 비율이 이론값에 수렴하는 과정을 봅니다.

  • 편향 동전(확률 조절) · 다면 주사위
  • 비율 편차 vs 횟수 편차
  • 최장 연속 기록, 도박사의 오류

모든 계산은 페이지 안에서 끝납니다(정적 사이트). 세율·요율·당첨금 같은 기준값은 매년 바뀌므로 각 페이지에서 직접 수정할 수 있게 해뒀습니다. 투자·세무 자문이 아니라 가정에 따른 산술 계산입니다.
